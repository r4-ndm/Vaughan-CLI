## Migration Guide

### From Crush
If you're migrating from Crush:
1. Backup your configuration
2. Install Vaughan Crush
3. Update your go.mod module path
4. Add blockchain-specific configurations
5. Test with Cast commands

### Configuration Changes
Version 1.x → 2.x (when released):
- Configuration format changes will be documented
- Migration scripts will be provided
- Backward compatibility maintained for at least one major version
